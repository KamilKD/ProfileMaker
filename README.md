# ProfileMaker
Конструктор чертежей профиля нефтепроводной трубы. Загружает геоданные трубы из Excel, выгружает горизонтальный и вертикальный профиль в dxf для просмотра в AutoCAD.

**Inputs**
В папке Input лежат два файла с примерами данных. Данные должны быть распределены по столбцам следующим образом:
Порядковый № точки | Координата X| Координата Y | Координата  Z| Глубина заложения

Sample1 - просто 5 точек для проверки работоспособности
Sample2 - 100 точек со сгенерированными данными, для более менее адекватной отрисовки планов

**Settings**
Sample2 сгенерирован таким образом чтобы настройки масштаба по умолчании позволили максимально наглядно отобразить планы.

**Outputs**
После загрузки данных из Excel, можно выгрузить три вида файла:
Excel файл с интерполированными точками, для более удобного отображения плана
dxf файл с проекцией линии трубы на горизонтальную плоскость 
dxf файл с проекцией линии трубы на вертикальную плоскость
